AURA-MPC: Atmosphere Unified Radiation Assessment - Model Predictive Control for Photovoltaics

AURA-MPC is a project dedicated to improve the electrical efficiency of solar panels through the use of model predictive control using a trained neural network.

The neural network is trained in a matlab sandbox with reinforcement, on experimental data from various laboratories and field studies, and on synthetic data generated using RK4 and RK45.
This was a choice that proved to be difficult.
The original project was geared towards simulating the change in temperature over time using different methods. When that was complete, the attention turned towards the use of PINN's (physics informed neural networks) working with a number of simulations of varying computational costs and accuracies with the intention of modeling live data and predicting into the future based off that live data. Although that is no longer what we are working on, it is still something we find quite interesting and would love to pivot back to in the future. Despite that, when we found that our initial hypothesis was wrong we knew it was time to shift to a sure fire method to reduce our uncertainties and move forward.
We base the current iteration of AURA-MPC off that project. at the root of this repository there is a LICENSE, a README.md, a notes.txt, a make.sh, and three folders: DAQ (for data acquisition), PINN (for physics informed neural network), and RK4TRAN (for runge kutta 4 (for)tran).
